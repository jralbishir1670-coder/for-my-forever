# Contributing to For My Forever ❤️

Thanks for helping make this project beautiful and accessible. Please follow these guidelines when contributing.

Branching
- Use `feat/`, `fix/`, `chore/`, `docs/` prefixes. Example: `feat/gallery-lightbox`

Commit messages
- Follow Conventional Commits: `type(scope): short description`.
- Example: `feat(gallery): add lightbox with keyboard navigation`.

Pull Requests
- Keep PRs focused and small.
- Use the provided PR template and link related issues.
- Include testing steps and screenshots for UI changes.

Coding standards
- Use React 19, Vite, Tailwind CSS, Framer Motion.
- Prefer small, reusable components. Follow SOLID, KISS, DRY.
- Accessibility: semantic elements, keyboard navigation, ARIA when necessary, alt text for images, captions for video.

Linting & formatting
1. Install dependencies: `npm install`
2. Run lint: `npm run lint`
3. Auto-fix: `npm run lint:fix`

Tests
- Add unit tests where appropriate. Use a lightweight testing strategy.

Local dev
- Start dev server: `npm run dev`

Thank you — your contributions make this project better.
